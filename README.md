## 🛠️ Featured Project: Secure Home Lab & Cybersecurity Sandbox

### Project Overview
This project highlights the design, deployment, and maintenance of a secure personal infrastructure built to test cybersecurity principles, manage local data integrity, and optimize network privacy. By leveraging open-source tools, virtualization, and dedicated hardware, I created a functional ecosystem that serves as both a secure personal cloud and a safe testing ground for security assessment tools.

### 🖥️ Hardware & Core Architecture
* **Physical Server:** Dell OptiPlex 3050 Micro, optimized for low power consumption and continuous uptime.
* **Virtualization & OS:** Deployed Proxmox as a hypervisor to manage isolated virtual machines, alongside CasaOS for streamlined container management.

### 🛡️ 1. Security & Pentesting Sandbox (Kali Linux)
* **Purpose:** Established a dedicated, isolated workspace to practice vulnerability identification, network auditing, and traffic analysis.
* **Implementation:** Deployed a Kali Linux virtual machine within a controlled environment to safely experiment with security frameworks and penetration testing utilities, ensuring execution remains strictly separated from the production home network.

### 🛑 2. Network-Wide Privacy & Security Gate (Pi-hole)
* **Purpose:** Mitigate network-based tracking, block malicious domains, and reduce overhead traffic for all connected devices.
* **Implementation:** Configured Pi-hole to act as a local DNS sinkhole. Implemented custom blocklists to intercept telemetry and corporate tracking, providing a clean and monitored pipeline for local traffic.

### ☁️ 3. Self-Hosted Cloud & Media Storage (CasaOS & Immich)
* **Purpose:** Establish absolute ownership over personal data, eliminating reliance on third-party public cloud providers while maintaining high availability.
* **Implementation:** Deployed Immich via Docker containers to manage automated, secure image and media backups. Practiced strict identity and access management (IAM) principles to configure fine-grained user permissions.

### 🌐 4. Secure Remote Access & Automation
* **Purpose:** Maintain secure, encrypted access to the home lab from external networks without exposing ports to the public internet.
* **Implementation:** Implemented a global VPN tunnel utilizing Tailscale to unify the network infrastructure securely. Additionally, utilize Python scripting for task automation and log parsing.
